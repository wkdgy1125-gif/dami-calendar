📲 앱 설치

  1. 크롬으로 열어요. (카카오톡·Claude 앱 안에서는 설치가 안 돼요 → 아래 「브라우저에서 열기」)
  2. 오른쪽 위 ⋮ → 「앱 설치」 또는 「홈 화면에 추가」 → 「설치」
  3. 삼성 인터넷이라면: 아래 ≡ → 「현재 페이지 추가」 → 「홈 화면」
  4. 홈 화면에 생긴 「담」 아이콘을 누르면 앱으로 열려요.
  1. 반드시 사파리로 열어요. (카카오톡·Claude 앱 안이면 아래 「브라우저에서 열기」 → 사파리)
  2. 화면 아래 공유 버튼(□↑)을 눌러요.
  3. 목록을 올려 「홈 화면에 추가」 → 오른쪽 위 「추가」
  4. 홈 화면의 「담」 아이콘을 누르면 앱으로 열려요.
아이폰은 설치 버튼이 따로 없어서 위 방법으로만 설치할 수 있어요.
📅 폰 캘린더 앱에 담이 일정 넣기 삼성·구글·아이폰 기본 캘린더에 담이 일정이 함께 떠요. 여기서 일정을 바꾸면 폰 캘린더에도 자동으로 반영돼요(보통 몇 시간~하루 걸려요).
구글 캘린더에 추가 (안드로이드)
구글 계정으로 로그인 → 「추가」. 삼성 캘린더는 설정 → 캘린더 관리에서 구글 계정 캘린더를 켜면 같이 보여요.
아이폰 캘린더에 구독하기
「구독」 → 「추가」를 누르면 끝이에요. 안 되면 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 「구독 캘린더 추가」에 아래 주소를 넣어 주세요.
📅 폰 캘린더 연동 삼성·구글·아이폰 캘린더 연동은 Cloudflare에 올린 담이 캘린더 앱에서 쓸 수 있어요.
