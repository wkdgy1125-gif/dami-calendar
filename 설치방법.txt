담이 전용 캘린더 앱 설치 방법
==============================

이 폴더는 "설치형 웹앱(PWA)"입니다. 타설집계 앱과 같은 방식이에요.
인터넷 주소(https)에 한 번 올려두면 휴대폰·PC 어디서나 그 주소로 들어가
"앱 설치 / 홈 화면에 추가"를 할 수 있습니다.
설치 후에는 「담」 아이콘으로 실행되고, 주소창 없는 전체 화면으로 열리며,
한 번 실행한 뒤에는 인터넷이 없어도 동작합니다.

※ 파일을 휴대폰에 복사해서 직접 여는 방식으로는 앱 설치가 되지 않습니다.
  (앱 설치는 https 주소에서만 가능한 브라우저 규칙)


1단계. 무료로 인터넷에 올리기 (GitHub Pages, 약 5분)
--------------------------------------------------
1) github.com 에 로그인 (타설집계 올린 계정 그대로)
2) 오른쪽 위 [+] → New repository → 이름: dami-calendar → Public → Create
3) "uploading an existing file" 클릭 → 이 폴더의 파일 전부를 끌어다 놓기
   (index.html, manifest.webmanifest, sw.js, icon-*.png, apple-touch-icon.png)
   → Commit changes
4) 저장소의 Settings → Pages → Branch: main / (root) → Save
5) 1~2분 뒤 https://wkdgy1125-gif.github.io/dami-calendar/ 주소로 열림


2단계. 휴대폰에 설치
--------------------
[안드로이드 - 크롬]
  위 주소 접속 → 화면 위쪽 [앱 설치] 버튼, 또는 메뉴(⋮) → "앱 설치"/"홈 화면에 추가"

[아이폰 - 사파리]
  위 주소 접속 → 위쪽 [앱 설치] 버튼에 나오는 안내대로
  아래 공유 버튼(□↑) → "홈 화면에 추가"

[PC - 크롬/엣지]
  주소창 오른쪽의 설치 아이콘, 또는 화면의 [앱 설치] 버튼


업데이트할 때
-------------
GitHub 저장소의 index.html을 새 파일로 바꿔 올리면,
앱을 다음에 인터넷 연결된 상태로 열 때 새 버전이 적용됩니다.


플레이스토어용 안드로이드 앱(APK/AAB)이 필요하면
-------------------------------------------------
1단계로 올린 주소를 pwabuilder.com 에 입력하면
이 웹앱을 감싼 안드로이드 패키지를 만들 수 있습니다.


데이터 저장 관련
----------------
- 기본 일정 73개(나라 지원금 기한·검진·접종·이벤트, 관련 링크·정보 출처 포함)가
  처음부터 들어 있어요.
- 추가·수정한 일정은 그 기기 안에 자동 저장됩니다(기기끼리 자동 공유는 안 됨).
- 앱을 삭제하면 그 기기에 저장된 일정도 지워져요.

가족과 같은 일정을 함께 보고 싶다면 (선택)
------------------------------------------
- 함께 드린 dami-calendar-worker.js 를 Cloudflare Worker로 올리고(KV 이름 CAL 연결),
  index.html 위쪽의  window.DAMI_API='';  따옴표 안에 그 주소를 넣어 다시 올리면
  가족 모두 같은 일정을 보고, 편집은 비밀번호(기본 123)로 할 수 있어요.
- 그때는 [📅 폰 캘린더] 버튼으로 삼성·구글·아이폰 기본 캘린더 연동도 돼요.
